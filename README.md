# Flora Terra · October 2026 (final, Harvest Table)

Browse: https://jc1147.github.io/flora-terra-october/  ·  Download all: https://github.com/jc1147/flora-terra-october/archive/refs/heads/main.zip

- `kits/` — all 23 October deal graphics in the five sizes from the deal sheet, named per deal:
  `Flora Terra - Promotions Icons (1000 x 1000)`, `Flora Terra - Homepage Deal Cards (484 x 230)`,
  `Flora Terra - Text x Email (1024 x Variable Length)`, `Flora Terra - Meadow Desktop Banner (1920 x 600)`,
  `Flora Terra - Mobile Banner (800 x 360)`; `kits/sheets/` shows each deal's five sizes on one page; `kits/manifest.json`
  lists every file with its sheet row and deal words.
- `emails/` — 17 emails: `email.html` (images beside it in `img/`), `phone-full.png` (full screenshot),
  `phone-screen.png` (first phone screen). The 8 day emails, the Oct 1 launch, the 4 Monday week overviews
  (`final-week-octNN`) and the 4 Dime Day spotlight options (`final-dime-spot-a..d`, client to pick one; each is the
  Oct 10 send — the Oct 20 / 30 sends swap in Tuesday's / Friday's deals).
- `plan/` — `october-emails.csv` (16 approved sends, each mapped to its email), `october-texts.csv` (8 proposed texts,
  pending client approval), `october-plan.json`, `october-2026.csv` (every date x every deal running that day).

Deal wording everywhere is the client's October sheet, word for word (brand names in their own caps).
Placeholders: Every Day Punch 10% off (Rosin All In Ones) and Quiet Kings Buy 2, Get 1 have no product photo yet.
Fonts: the brand fonts are licensed and are not included; the email HTML falls back to similar fonts.
